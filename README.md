# 🏴‍☠️ Jolly Roger

Jolly Roger is a pirate-themed Discord bot with adventures, battles, treasure, and an economy system.

Build your ship, collect treasure, explore adventures, battle other captains, and grow your pirate fortune.

## ✨ Features

- 🗺️ Interactive adventures
- ⚔️ Pirate battles
- 💰 Coins and treasure
- 🎒 Collectible items
- 🚢 Ship upgrades
- 🏆 Leaderboards
- 🎁 Vote rewards
- 🦜 More features and adventures added over time
